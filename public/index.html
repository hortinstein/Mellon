Doctrine

I

Post-Post-Quantum

Quantum computers explore every state at once. Mellon is already in every state at once. There is no algorithm to run against it, because it is not running one.

II

Zero keys. Zero math.

The warfighter cannot recall a 4,096-bit key under fire. They can explain who they are and why they belong here. Mellon listens.

III

Fail-closed doctrine

When the uplink drops, nobody gets in. Not the adversary. Not the warfighter. Not the general. Perfect parity of denial across the kill chain.

Technology

How Mellon decides.

FIG. 1

Adjudication flow

Every request becomes three typed questions to TypeSafe Jev: a grant-or-deny choice, a compliance score and a manipulation probability. Jev returns numbers, not prose.

A policy engine in plain code compares those numbers against the lock's thresholds. Only then is the payload decrypted. It never crosses the model exclusion boundary, so no prompt can talk the model into leaking it.

FIG. 2

System architecture

One Node process with zero runtime dependencies. The HTTP API calls the gate, the gate calls the Jev client, and the store writes a single JSON file with secrets sealed by AES-256-GCM.

The only outbound call is to Jev. Without an API key, Mellon drops to DDIL mode and its offline judge denies nearly everything.

FIG. 3

Quantum threat model

Shor's algorithm breaks RSA by factoring its modulus. Mellon has no modulus. A quantum adversary must therefore state its business in plain English, where the Manipulation Index is waiting.

Engineering note: this figure is satire. The real quantum posture is AES-256-GCM at rest, roughly 128-bit secure against Grover, plus whatever TLS your runtime negotiates with Jev.
